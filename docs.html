User

API for managing user profiles, data, and follow relationships. All requests are expected to already be authenticated by the gateway. Information retrieved by that authentication is expected to be passed in the request headers by the gateway, while other information is expected to be passed in the request body by the sender.

Search users.

Searches for users by username, first name, or last name with prioritization. Results are prioritized: followed users first, then by match type (username > firstName > lastName). The searching user is excluded from results. Query must be at least 2 characters long. Page size is limited to maximum 100.

query Parameters
q
required
string [ 2 .. 2147483647 ] characters
Example: q=john

Search query.

required
object (OpenAPI_definition_Pageable)
Example: pageable=page=0&size=20

Pagination parameters. Default: page=0, size=20. Maximum size=100.

header Parameters
X-User-Id
required
string

User ID retrieved from authentication

Responses

Generated server url

http://localhost:3002/api/user/search

Gateway: Conversation

API for managing conversations (direct messages). All requests are expected to already be authenticated by the gateway. User information is extracted directly from the JWT token in the SecurityContext.

Creates a new conversation between the authenticated user and a participant. The participantId is verified to exist before creating the conversation. This endpoint forwards the request to dm-service to create the conversation.
